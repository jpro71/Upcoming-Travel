# Upcoming Travel Planner

## Overview

Personal travel planning application built with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase

The goal is to create a polished travel planning application that stores every aspect of a trip in one place.

---

# Development Philosophy

- Build working features first.
- Refactor only when there is a clear long-term benefit.
- Use complete file replacements whenever practical.
- Commit completed features to Git.
